# Регламент работы с контентом Яндекс Дзена (`dzen-mcp`)

Этот файл задаёт обязательные правила работы агента в проекте `D:\dzen-mcp`.

## 1. Запрет на генерацию картинок
- **Никогда не генерируй обложки и иллюстрации через ИИ** (Дзен пессимизирует публикации с ИИ-картинками).
- Параметр `image_path` (в `create_dzen_article`) и `image_paths` (в `create_dzen_post`) используй **только** при явной передаче пользователем пути к готовому локальному файлу.
- Во всех остальных случаях создавай публикации без изображений (`image_path=None`, `image_paths=None`).

## 2. Пайплайн подготовки контента

### Этап A — Аналитика канала (`prompts/02_Карта-заголовков.md`)
1. По запросу пользователя вызови MCP-инструмент `dump_channel_articles(slug, days)` (выгрузка сохраняется в `D:\dzen-mcp\exports\<slug>_статьи_<days>дней.txt`).
2. Прочитай промпт `D:\dzen-mcp\prompts\02_Карта-заголовков.md` и строго по его структуре (9 обязательных разделов, включая автономную секцию 8 «Кит генерации») проанализируй выгруженные заголовки.
3. Сохрани итоговую карту в `D:\dzen-mcp\knowledge\<slug>_map.md`.

### Этап B — Редполитика ниши (`prompts/03_Сборщик-системы.md`)
1. На основе примеров статей (1–3 полных текста) и карты заголовков из `D:\dzen-mcp\knowledge\<slug>_map.md` прогони методику `D:\dzen-mcp\prompts\03_Сборщик-системы.md` (3 прохода).
2. Собери и сохрани три файла в `D:\dzen-mcp\knowledge\<niche>\`:
   - `ИНСТРУКЦИЯ.md`
   - `СТИЛЬ.md`
   - `СТРУКТУРА.md`

### Этап C — Написание и отправка в черновики (`create_dzen_article`)
При написании любой статьи для Дзена строго соблюдай правила антишлака и типографики из `prompts/03_Сборщик-системы.md`:
- **Тире:** длинное тире `—` запрещено. Среднее `–` редко (максимум 3–5 на статью, в диалогах и диапазонах). Вместо тире используй запятую, точку, союз или двоеточие; дефис — только в составных словах.
- **Кавычки:** только «ёлочки».
- **Живой ритм и абзацы:** короткие живые абзацы (преобладают 1–2 предложения); чередуй короткие, средние и длинные предложения (не 3+ коротких подряд и не 2+ длинных подряд), союзы в начале 20–30% предложений.
- **Антишлак:** вычищай ИИ-клише и канцелярит («однако» → «но», «затем» → «потом», «является» → «это», «данный» → «этот», «осуществлять» → «делать», убирай «стоит отметить», «в современном мире» и подобные штампы).
- **Явность:** ключевые факты и выводы формулируй прямо словами, без расплывчатых намёков.
- **Структура Markdown для редактора Дзена:** используй `## ` для подзаголовков, `> ` для цитат, `- ` для списков, `**...**` для смысловых акцентов.
- **Публикация:** всегда отправляй готовый текст в черновики через `create_dzen_article(..., publish=False)`, если пользователь явно не попросил сразу опубликовать (`publish=True`).
